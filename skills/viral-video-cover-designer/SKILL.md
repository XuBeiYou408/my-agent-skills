# Viral Video Cover Designer (全平台高点击率视频封面设计引擎)

本 Skill 旨在解决创作者“做不出吸睛爆款封面”的痛点。深度融合了**【秋芝2046 戏剧化大头隐喻风】**、**【微型计算机 50期硬核实测参数】**、**【电影级深度访谈社论风】**以及**【URL 直驱数据报道破局风】**四大流量视觉体系。

---

## 🚦 一、 核心工作流：确认制省流提案流程

```mermaid
flowchart TD
    In[用户输入: 实拍图 / 文案 / 仅提供网页报道链接 URL] --> CheckURL{是否为网页链接?}
    
    CheckURL -- 是 (URL 直驱) --> Fetch[自动调用读网页工具抓取文章与跑分数据]
    CheckURL -- 否 (图文输入) --> Parse[多模态语义解构与动线分析]
    
    Fetch --> Parse
    Parse --> Propose[输出 2~3 组差异化创意方案<br>⚠️ 每个方案强制绑定专属 ASCII 线框图]
    Propose --> Decision{用户选择方案<br>(或提出微调意见)}
    Decision --> Render[【精准出图】仅对选中的方案消耗 1 次额度渲染]
    Decision --> Export[【通用导出】提供单一全通用生图提示词包]
```

### 🔒 门禁铁律：方案卡片「原子化五要素」强绑定（Atomic Contract）
每个方案（方案 A、方案 B、方案 C...）**必须严格且无一例外包含以下 5 个字段，严禁缺失**：
1. **【方案名称】**：核心人设与戏剧冲突；
2. **【主体形态与视角】**：具体换装、大头表情、手势动线或硬件宏观视角；
3. **【剧情道具与光影】**：3D 全息悬浮物、反差道具、环境氛围；
4. **【大字报文案与字效】**：严格 4~8 字，注明主文字色、描边与硬立体阴影；
5. **【专属 ASCII 结构排版线框图】**：**必须紧跟在每个方案下方！提几个方案就必须有几个线框图，严禁任何方案省略线框图！**

## 🌐 二、 URL 链接直驱解析机制（URL-Driven Auto Ingestion）

当用户仅扔来一个**文章链接（如官方发布博客、新闻报道、论文公告、科技媒体链接）**时：
1. **静默自动抓取**：自动调用网络读取工具提取网页正文与表格数据，无需用户手动复制粘贴；
2. **三维冲突提炼**：
   - **大事件定性**：官方突发、重磅更新、价格屠夫、技术革命；
   - **杀手级数字**：找出最刺眼的反差数据（如：成本降 90%、速度翻 5 倍、跑分断层第一）；
   - **对标竞品**：自动提取被碾压的竞品型号（如 GPT-4o、Claude 3.7、RTX 5090）。
3. **直通四大引擎**：根据抓取内容自动匹配最佳视觉流派。

## 🎭 三、 四大风格引擎自适应路由

### 1. 默认引擎：【秋芝戏精隐喻流】（适用：消费级 AI、工具教程、趣味生活）
* **核心公式**：`真人大头透视` + `脚本角色剧情换装` + `3D 悬浮道具` + `电光黄立体大字报`
* **人像规范**：100% 锁定用户原摄五官发型，微放大 1.25x~1.35x 增强大头情绪张力（大张嘴惊呼/挑眉），轮廓加 15px 发光光晕剥离背景。
* **字效规范**：**4~8 个核心大字**，字高占画面 22%~26%，**秋芝电光黄 `#FED700`**，双层纯黑描边 + 向右下偏 `(+10px, +14px)` 的纯实底硬立体阴影。

### 2. 硬件引擎：【微机硬核实测流】（适用：显卡、CPU、主板、电源实测拆解）
* **样本提取固定参数**：画布 16:9，双行结构（占比 84%），单行 6~8 字，逆时针倾斜 `-4.0°`。
* **色彩池**：文字纯白 `#FFFFFF`，描边纯黑 `#000000`，**微机记号黄底衬 `#F8C039`**，AMD/警示红 `#ED1C24`，Intel/评测蓝 `#00A3E0`。
* **核心元素**：芯片微距底图 + 毛玻璃对决横幅（Glassmorphism） + 斜角巨大**“拆！”**字印章。

### 3. 访谈引擎：【电影级深度社论流】（适用：行业专访、创始人对话、圆桌播客）
* **⚠️ 绝对红线铁律（人像 0 篡改）**：严禁换装、修脸、改表情、改动作或卡通化！100% 保留嘉宾原摄真实眼神、服饰与皮肤质感。
* **视觉语法**：单侧伦勃朗光影 + 背景暗化景深虚化 + **巨型香槟金双引号 `“ ”`** 框定破局金句 + 身份背书标签（`[ 独家专访 · 首席科学家 ]`）。

### 4. 数据与速报引擎：【纯报道/数据图驱动流】（适用：无素材，仅报道链接或跑分数据）
* **A. 跑分破顶撕裂流**：将数据转化为 3D 实体发光柱，新模型柱条**“冲出画面顶部天花板、伴随雷电碎裂特效”**碾压竞品。
* **B. 科技图腾降临流**：生成 3D 悬浮多维科技核心，环绕透明数据 HUD 看板（标注关键降幅/倍率）。
* **C. 突发绝密速报流**：深色极客终端背景，斜角加盖高对比度红印章（**“突发重磅！”、“全量免费”、“屠榜全场”**）。

## 📐 四、 多平台三大画幅自适应矩阵

- **`16:9`（B站横版 / YouTube）**：左右开阔横排，**右下角 $[80\%, 100\%] \times [85\%, 100\%]$ 严格留白**，避让时长码；
- **`4:3`（B站动态 / 专栏 / 平板）**：横向收紧，大字报上下聚拢，道具紧贴主体；
- **`3:4`（小红书 / 视频号 / 抖音）**：经典竖屏海报流，主体位于中下部，顶部黄金区域垂直堆叠超大字报。

## 🔌 五、 运行时解耦与【单一通用提示词导出规范】

当宿主 Agent 缺乏生图插件、配额耗尽、或用户需在网页端生成时，输出**唯一全平台通用提示词**（兼容网页端 ChatGPT、Gemini、Midjourney、即梦、可灵）：

```text
请为我生成一张 [画幅比例] 的高质量视频封面。
【核心主体】：[若有图：参考我上传的原图素材 / 若无图：3D 拟物化破顶跑分柱状图 或 悬浮科技核心]
【场景与道具】：[电影级场景、3D 全息数据看板、反差道具或突发印章]
【背景光影】：[冷暖对比光、科技暗调景深虚化]
【大字报排版】：顶部横贯超大 3D 立体大字报：'[核心标题]'，采用高饱和电光黄（#FED700）纯黑粗描边与硬立体阴影，右下角严格留空避让时长码。
```
