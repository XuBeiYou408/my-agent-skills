# Viral Video Cover Designer (科技视频封面设计引擎 · 逐层步进积木版)

本 Skill 旨在解决科技数码及深度内容创作者“做不出吸睛爆款封面、文字排版难看/错字、大模型随意篡改原图主体、或不给用户确认机会擅自抢跑生成”的致命痛点。

系统精准确立并严格支持**四大核心风格**：
1. **【1. 微机风格】**（真人主持出镜实测与工作流 · 30套样本深度优化）
2. **【2. 纯硬件宣传 / 拆解与旗舰PK】**（无真人出镜 · 芯片微距/拆解/旗舰PK）
3. **【3. 电影级深度社论】**（专访与播客 · 人像100%绝对零篡改 · 伦勃朗光与双引号金句）
4. **【4. 纯数据报道类型】**（零图片素材 · 静默抓取链接 · 3D破顶能量柱与全息星核）

---

## 🔒 核心红线一：【基于用户原图修改强绑定与垫图路径强校验协议】

**在生成提示词（Prompt）或调用生图工具时，必须向大模型施加强制约束：必须严格基于用户上传的原图进行增量修改与重构，严禁抛弃原图凭空捏造全新的陌生人物或硬件！**

### 1. 垫图路径精准识别与防误取铁律：
- **严格区分真实素材图与辅助说明图**：当用户在会话中同时上传人像/硬件照片与聊天记录截图、文字说明图时，**系统必须通过视觉解析精准锁定真实人像/硬件的照片路径**作为生图垫图（ImagePaths），**严禁将文字截图或排版参考图误传为人物垫图**，彻底杜绝因参考图错位导致的人像退化、换脸与变相问题。

### 2. 分风格原图保真与修改铁律：
* **在【1. 微机风格】中（真人实操）**：
  - **主体锁定**：必须 100% 锁定用户原图中的五官长相、眼镜配饰、发型、骨骼比例与真实肤质，**绝对禁止生成随机网红脸、AI 假人脸或卡通脸**；
  - **增量修改**：在原图人物基础上进行增量环境合成——微调手臂与手势（双手托举硬件、自然指向屏幕痛点），在人物边缘施加通透的冷暖漫反射轮廓光，替换杂乱背景为暗调极客工作室。
* **在【2. 纯硬件宣传 / 拆解与旗舰PK】中（硬件物料）**：
  - **主体锁定**：必须 100% 忠实保留用户原图中的硬件设备（主板、显卡、整机、手机、芯片等）真实外形结构、接口布局、散热鳍片、螺丝点位与品牌 Logo，**绝不替换为幻觉出的其他产品**；
  - **增量修改**：将拍摄背景替换为极客防静电工作台或哑光深色金属台面，施加 100mm 工业微距景深，强化金属切角与电路板走线的高光质感，中下部叠加半透明毛玻璃参数通栏。
* **在【3. 电影级深度社论】中（专访对话）**：
  - **主体锁定（100% 绝对零篡改）**：嘉宾面部五官、表情神态、眼神聚焦、发型胡须、乃至西装衬衫完全锁死，**像素级保留真实纪录素质感**；
  - **增量修改**：仅做环境光影与氛围重构——单侧施加电影级伦勃朗光影（三角高光区），背景压暗为高景深暗调工作室，在空白区域框定巨型香槟金双引号金句与身份背书铭牌。
* **在【4. 纯数据报道类型】中（无原图链接直驱）**：
  - 若用户未提供图片，则以抓取的数据表合成 3D 能量柱；若用户提供了新闻截图或官方图表，必须以该截图数据为锚点进行 3D 实体化还原。

## 🔒 核心红线二：【物理级逐层强停机门禁（Hard Breakpoint · 严禁抢跑）】

为彻底消除黑盒随机生成的失控感与错字隐患，严格执行**逐层步进交互（Layer-by-Layer Progressive Gating）**：
1. **每层必须停机等待用户指令**：每一层给出 5 组贴中文案的差异化选项后，**当前轮次必须立即停机（STOP），结束当前回复**；
2. **选定后必吐累积排版线框图**：用户回复选定某层组件及位置后，系统必须立即输出当前层级叠加后的 ASCII 排版线框图，供用户直观核验布局；
3. **严禁越层合并生成**：绝对禁止在用户未确认前擅自跳步预设后续层级或直接调用生图工具。

## 🧱 二、 逐层步进积木拼装引擎（每层 5 维组件矩阵）

在每一层，系统必须根据用户输入的具体文案与物料，动态推导出 **5 个不同维度方向（A / B / C / D / E）** 的组件供用户挑选，并支持九宫格自由定位：

### 📍 九宫格排版标准定位锚点：
- **`TL`**（左上角）：主标题大字报、突发警告条；
- **`ML`**（左中）：悬浮科技道具、3D 芯片、全息星核；
- **`BL`**（左下角）：参数毛玻璃胶囊、规格通栏、底衬墨迹；
- **`TC`**（顶部通栏）：副标极客说明、品牌标识；
- **`MC`**（正中心）：微距芯片主体、爆炸火花、VS 碰撞中轴；
- **`BC`**（底部通栏）：跨屏双雄对抗通栏；
- **`TR`**（右上角）：-15° 倾斜红色盖印、漫画气泡；
- **`MR`**（右中）：主持人出镜身位、手势交互起点；
- **`BR`**（右下角）：**⚠️ 绝对禁区！预留给平台视频时长码，严禁放置核心文字与关键细节！**

---

### 🔹 Layer 1: 场景基底与空间光影（5 维方向）
1. **`1A (硬核极客工坊)`**：深灰黑大景深背景，虚化浮动暗青色终端代码瀑布与电路暗纹，突出真实极客开发与实测。
2. **`1B (冷暖对冲实战台)`**：好莱坞双色布光，左侧深海冷蓝光场 vs 右侧暖橙边缘轮廓光（Rim Light），制造戏剧张力。
3. **`1C (极简纯黑发布会)`**：类似 Apple Keynote 的哑光深黑深空，顶部柔和下垂漫反射聚光，四周柔和暗角过渡，大气克制。
4. **`1D (暗夜极客窗景)`**：深色极客工作室窗景，后景透出微弱雨夜散焦霓虹光斑，充满“深夜独家揭秘”的真实生活感。
5. **`1E (全息数据虚空)`**：虚实交界的数字空间，地面带有半透明发光全息网格线（Grid Floor），深蓝紫渐变星空，未来感拉满。

---

### 🔹 Layer 2: 主体人物与核心道具（5 维方向 · 支持缩放与定位）
1. **`2A (极客终端实测)`**：主持人平端轻薄本（支持指定缩放，如放大 1.35x 居中），屏幕高亮展示真实架构拓扑与断崖式跑分折线图。
2. **`2B (实体硬核机甲/爪臂)`**：真实工业金属拉丝机械爪实体（带型号刻字），碳纤维走线与微型液压杆，爪心嵌发光核心。
3. **`2C (全息自转星核)`**：主持人扬手自然托举，掌心悬浮自转半透明全息光球，外环环绕 HUD 数据刻度圈与粒子光轨。
4. **`2D (版本撕裂双持对比)`**：主持人双手对比互动：左手托暗淡旧版本/竞品图标，右手托雷电爆裂的高亮新架构芯片。
5. **`2E (微距硬件特写视角)`**：人物退至后侧，双手将巨型微距主控核心推至镜头前沿，大浅景深聚焦硬件细节。

---

### 🔹 Layer 3: 核心文字排版与多样字体语法（5 维方向 · 基于 30 套生产级素材提炼）
高水准封面的核心在于文字的**语义角色混搭、字距紧锁与色彩阶梯**：
1. **`3A (撕纸干刷棋盘撞色)`**：破锋飞白体（街头撕纸干墨边缘）+ 力量粗黑；词组对角穿插填色（白+青 / 黄+白）；底部压动态青色笔刷划痕；
2. **`3B (情绪色彩三阶梯)`**：3 行垂直紧咬（行距 0.8em）：第1行纯白冷峻引子 → 第2行高亮柠檬黄破局（放大 1.25x）→ 第3行警戒红倾斜痛点（纯黑立体硬投影）；
3. **`3C (黑夜枯笔墨迹反转)`**：上行现代平滑发光粗黑体，下行核心爆点反衬在 **-4° 倾斜的纯黑枯笔飞白墨迹底衬** 之上（亮黄色字，边缘毛刺撕裂）；
4. **`3D (双雄星爆对抗通栏)`**：横贯中轴对抗：左侧冷蓝阵营字 vs 右侧橙金阵营字，中央连接词字号缩小并附带放射状火花爆炸底光；
5. **`3E (悬浮 HUD 3D 异形舱)`**：品牌/型号封装在带有 3D 倒角与厚度的高透全息框内，搭配极端高低落差字号（超小副词 + 超巨型动词）。

---

### 🔹 Layer 4: 次级符号、点缀印章与微排版（5 维方向）
1. **`4A (手绘粉笔涂鸦指引组)`**：白色粉笔手绘弯曲指示箭头（从大标题精准弯向屏幕/道具峰值），屏幕核心数据旁带 3 道手绘发散光芒线；
2. **`4B (斜切做旧实底印章)`**：-15° 逆时针倾斜的朱红油墨双线做旧印章（如 `【真没吹牛！】`、`【深度实测】`、`【绝密】`）；
3. **`4C (雾面毛玻璃参数胶囊)`**：半透明磨砂黑圆角胶囊通栏，内嵌纯白等宽机甲字符（如 `[ 2.0架构升级 · 性能跃升340% ]`），稳固画面重心；
4. **`4D (极客警戒斑马线)`**：沿边缘或切角排布黑黄工业警戒带，喷印 `CAUTION: MAJOR UPDATE`；
5. **`4E (纯粹极简留白)`**：零多余贴纸与胶囊，依靠纯净空间与大字自身张力呼吸。

## 🔤 三、 多样字体混搭与微排版技术规范

### 1. 语义字体混搭矩阵：
- **英文/型号/数字**：紧凑型大写几何无衬线（SF Pro Display / DIN / Impact），高瘦、字距紧缩；
- **核心动词/痛点**：破锋飞白体 / 干刷撕纸体，边缘带撕裂燥点；
- **主干事实/中立陈述**：高压紧凑力量粗黑（方正粗谭黑 / 造字工房力黑），中宫饱满，负字距；
- **戏剧冲突/人名**：黑白反转倾斜黑体，带有 -3°~-5° 动感微倾角；
- **辅助指示**：手绘马克笔体 / 极细等宽机甲字。

### 2. 严苛微排版三大铁律：
1. **负字距（Negative Kerning）**：字间距紧扣 -20 到 -50，汉字与数字之间紧贴，杜绝松散透光的“PPT 廉价感”；
2. **多层轮廓锁死（Multi-Layer Outlining）**：
   - 内部：字芯纯色或微渐变；
   - 中层：1~2px 内发光/切角高光；
   - 外层：4~6px 坚硬实心纯黑描边（Black Solid Stroke），确保在任何复杂背景或人像边缘**绝不吃字**；
   - 投影：深色硬边缘 3D 投影或广角暗辉光；
3. **字号落差节奏（Scale Hierarchy）**：副词/代词缩至 60%~70%，核心名词/痛点放大至 120%~140%。

## 🚀 四、 双轨工业级交付协议（彻底解决 AI 错字与排版瑕疵）

全图 4 层积木组装完成并经用户全景终审通过后，提供双轨交付选择：

### 轨道 A：【Track A · 一体化 AI 精准出图】
- **适用**：需要快速出图、一站式交付的场景。
- **机制**：将 4 层选定的积木语义注入提示词，严格传入用户真实原图路径进行高保真渲染。

### 轨道 B：【Track B · 100% 零错字工业级方案（无字底图 + 矢量排版层）】
- **适用**：对排版、字体字重、字形与汉字绝对零错字有像素级严苛要求的专业剪辑师/运营团队。
- **机制**：
  1. **4K 纯净无字底图**：大模型仅渲染人物、场景光影与 3D 道具，**背景与画面 100% 纯净无任何文字与杂质字符**；
  2. **矢量排版图层交付**：系统同步输出精准对齐的 **SVG 矢量文件 / CSS 排版规范 / 透明 PNG 字层**。剪辑师在剪映、Premiere、Photoshop、Figma 中一秒对齐贴合，字体重心、间距随意微调，100% 零错字、零边缘模糊、字字清晰。

## 🎨 五、 四大核心风格深度设计规范

### 🛠️ 1. 微机风格（真实主持出镜 / 工作流评测流）
* **适用场景**：博主/主持人真人出镜评测、开箱上手、生产力工作流实战。
* **原图锚定与修改要求**：
  - 严格保持用户上传原图中的五官发貌与形体比例（85mm 真实单反中焦无畸变）；
  - 修改增量：将原图背景剥离，将人物与深色极客工作室自然融合；调整手势为双手托举或指向硬件，施加冷调科技轮廓光。
* **重工字效与色彩**：
  - 经典双行结构，单行 6~8 字，文字整体逆时针 `-3.0° ~ -5.0°` 动感微倾角；
  - 字芯纯白 `#FFFFFF` + 纯黑极粗描边 + 向右下方硬朗延伸的纯黑 3D 硬实立体投影；
  - 微机记号笔明黄 `#F8C039` 矩形划痕底衬，紧扣文案核心关键词或硬件型号；
  - 斜角实底印章（按文案有机衍生：如【首测】、【真香】、【宝藏】）。

### 💻 2. 纯硬件宣传 / 拆解与旗舰PK（无人物出镜 · 拆解与旗舰PK）
* **适用场景**：用户仅提供硬件产品物料、工程样机、拆解主板、或明确要求不出现人物。
* **原图锚定与修改要求**：
  - **⚠️ 绝对铁律：严禁凭空生成虚假真人！** 纯粹聚焦硬件本身的工业美学；
  - 100% 还原上传原图硬件的物理接口、品牌标牌与电路特征；
  - 修改增量：置入 100mm 工业微距平视 / 45° 俯拍环境，强化金属切角高光反射、芯片蚀刻细节与电容阵列光影。
* **专用构件与字效**：

## 📐 六、 16:9 / 4:3 / 3:4 三画幅精准重构法则

- **`16:9` (1672×941 横屏 · B站/YouTube)**：左右开阔分栏，**右下角 $[80\%, 100\%] 	imes [85\%, 100\%]$ 严格留白**，避让时长码；

- **`3:4` (1086×1448 竖屏海报 · 小红书/抖音/视频号)**：纵向三层重构：顶部标题拆为 3 行垂直堆叠，中部主体居中下，底部横栏贯穿，全屏饱满无黑边。

## 🔌 七、 跨宿主环境生图与提示词导出规范

1. **在 Antigravity 宿主环境中**：
   - 直接调用 `generate_image` 工具；
   - `ImagePaths`: 严格传入真实人像/硬件照片的本地绝对路径（杜绝误传文本截图）；
   - `AspectRatio`: 对应画幅（`16:9` / `4:3` / `3:4`）；
   - `ImageName`: 英文小写下划线命名。
2. **在 WorkBuddy / AI-HIVE 宿主环境中**：
   - 优先通过 `upload_media_from_path` 换取 `mediaId`，再调用 `generate_image(imageMediaIds=[mediaId], ...)`；
   - 🔒 **防降级熔断铁律**：若图生图接口报错，**绝对禁止静默降级为纯文生图**！必须熔断并如实告知用户，输出通用修图 Prompt。
3. **外部生图平台（ChatGPT / Midjourney / 即梦）通用修图 Prompt 导出**：
   - 包含【核心修图指令】、【原图主体保真与增量修改】、【排版与重工立体大字】及【环境与场景氛围】四大必选板块。
