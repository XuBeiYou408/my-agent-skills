# Obsidian 会话自动归档技能 (Obsidian Archive Skill)

本技能用于在用户（幼麟）发出归档指令时，自动将当前对话提炼并保存至本地 Obsidian 知识库中。

## 📌 触发条件
当用户提及以下类似口令或意愿时自动触发本技能：
- “总结到 Obsidian” / “保存到 Obsidian”
- “归档到知识库” / “存入 Obsidian”
- “把这段对话记录下来”

## 📁 存储规范与任意 N 级目录树递归审查复用算法

- **知识库根目录**：`D:\obsidian-knows\`
- **通用目录路径结构**：`D:\obsidian-knows\[层级1]\[层级2]...\[层级N]\[纯文本文件名].md`

- **通用递归审查与复用算法（核心硬性法则，不限层级数）**：
  1. **层级语义拆解**：根据上下文归纳从粗到细的逻辑分类路径序列。
  2. **逐层递归检查与优先复用**：从根目录开始，依次审查第 $k$ 级。若存在匹配子文件夹，**强制优先复用**；无匹配时方可新建。
  3. **同步骤多方法解耦独立建卡**：对于同一主步骤下的不同工程手段，必须拆分为单张独立 Markdown 卡片，严禁混合平铺。
  4. **全景索引卡片规范 (Overview Index Card Rule)**：每一个四级优化模块子文件夹下，必须包含一张 `[模块名]工程痛点与优化全景.md`，集中展现痛点与解法映射，并提供精准跳转双链。
  5. **中英双语 + 口语化双解构法则（七重顶级架构）**：
     * 痛点：`[痛点中文专业术语]` (`[痛点英文专业术语]`) + 🗣️ **口语化痛点描述**
     * 方案：`[方案中文专业术语]` (`[方案英文专业术语]`) + 🗣️ **口语化方案解构** + 💡 **硬核架构卡点** + 🔗 **跳转双链**
  6. **Obsidian Mermaid 兼容防误判法则**：
     * `subgraph` 格式：`subgraph sub_id ["带双引号的显示标题"]`
     * 节点文本内部**绝对禁止使用 `1. `, `2. ` 等“数字+点+空格”格式**，避免 Obsidian 误判为 unsupported markdown list。
  7. **双链精准别名语法**：指向已有卡片时，**必须使用 `[[真实文件名|显示文本]]` 别名语法**！

## ⚙️ 执行流程与注意事项
1. **多层级递归审查**：自顶向下审查 Level $1 \rightarrow N$，有匹配则复用，无匹配则新建。
2. **构建全景索引与明细卡片 Markdown**：填充上述模板。
3. **写入叶子文件**：使用 `write_to_file` 写入 `D:\obsidian-knows\[层级1]...\[层级N]\[纯文本主题名].md`。
4. **反馈用户**：输出成功保存提示（列出生成的卡片链接）。
