# 自然语言驱动的前端设计智能全景工程规范 (Unified Natural Frontend Intelligence)

本 Skill 将 **Taste-Skill（视觉审美、生图情绪板、风格预设与旋钮调节）** 与 **Impeccable（23 维设计语义、59 条确定性质检与全状态防御）** 深度整合。
**核心原则：用户无需输入任何命令或记住专业术语，日常口语沟通即可全自动触发两者的完整能力闭环。**

---

## 一、 Taste-Skill 专属核心能力：自然语言映射与落地

### 1. 风格流派与设计旋钮（Style Archetypes & Dials）
用户无需配置数值，根据口语自然匹配风格预设与参数：

| 用户自然语言口语表述 | 触发风格流派 / 旋钮调节 | 落地设计特征 |
| :--- | :--- | :--- |
| **“做得性冷淡/极简一点/不要任何多余装饰”** | **`Minimalist` 极简风**<br>`VARIANCE: 6, DENSITY: 3` | 极致负空间（巨大留白）、克制单色系、去除所有卡片阴影与外边框，靠严谨字阶与排版形成视觉骨架。 |
| **“硬核一点/极客风/复古粗糙/粗野派”** | **`Brutalist` 粗野风**<br>`VARIANCE: 8, DENSITY: 7` | 粗黑边框（2px-3px solid）、等宽字体（Monospace）、高对比鲜明撞色、硬投影（Offset box-shadow）、拒绝圆角。 |
| **“做温暖柔和一点/小清新/轻盈/磨砂感”** | **`Soft UI` 柔和风**<br>`VARIANCE: 5, DENSITY: 4` | 大圆角（16px-24px）、弥散柔和阴影、暖色系中性色（Warm Slate）、毛玻璃微透明质感（Backdrop Blur）。 |
| **“这是一个数据后台/要做很多图表/信息量很大”** | **`High-Density SaaS` 高密生产力**<br>`DENSITY: 8, VARIANCE: 3` | 紧凑行距、微型状态徽章（Badges）、数据可视化对齐、微型操作栏、多级可折叠过滤面板。 |
| **“更大胆先锋一点 / 规矩一点别太跳脱”** | **`DESIGN_VARIANCE` 旋钮动态调控** | 先锋（7-9）：非对称布局、视觉破格、大字叠图；<br>稳健（2-4）：严谨对称多栏、标准网格系统。 |

### 2. 视觉参考板与生图提示词生成（Image-Gen & Brandkit）
当用户需要**找灵感、定品牌调性、或准备生图给 AI 作参考**时：

| 用户自然语言口语表述 | 触发能力 | 产出内容与流程 |
| :--- | :--- | :--- |
| **“帮我想一套品牌设计规范 / 配色方案”** | **`brandkit` 品牌调性板** | 输出：<br>1. **核心色盘**：主色、强调色、3 种深浅中性色（带色偏）、危险/成功语义色。<br>2. **字体家族搭配**：Display 标题字体 + Sans 正文字体 + Mono 代码数字字体组合推荐。<br>3. **生图提示词**：可直接粘贴至 Midjourney / ChatGPT 的高保真品牌规范展板提示词。 |
| **“先帮我画几个网页/App 设计参考图 / 给点生图 Prompt”** | **`imagegen-frontend` 视觉情绪板** | 输出符合工业级 UI 标准的生图提示词（包含 `8k, clean UI layout, Figma presentation, Dribbble trending, accurate typography hierarchy, responsive frames`），生成切片式 UI 概念看板。 |

### 3. 设计走查重构与图生代码（Redesign & Vision-to-Code）
当用户提供现有代码或上传参考截图说：
- **“参考这个图帮我做出来”**：Agent 自动提取图中的色彩倾向、间距比例、字体权重和层次关系，转换为标准可维护的前端组件。
- **“帮我把现有的老旧页面重构成现代风格”**（触发 `redesign-skill`）：Agent 先剖析旧版 3 大设计硬伤，再按照现代设计规范全盘重写。

## 二、 Impeccable 专属核心能力：自然语言映射与防御

### 23 维设计工程动作映射

| 用户自然语言口语表述 | 底层映射动作 | Agent 具体实施规范与动作 |
| :--- | :--- | :--- |
| **“太普通了/不够吸睛/没亮点/抓不住眼球/太平淡”** | **`bolder` + `craft`** | 1. 扩大排版字阶比率；2. 确立单一强视觉锚点；3. 强化主要行动按钮（CTA）实体质感与环境光。 |
| **“太乱了/花里胡哨/收敛点/简单干净点/太吵了”** | **`quieter` + `distill`** | 1. 剔除多余描边与渐变；2. 统一中性色调，卡片改用负空间隐式分割；3. 降低视觉噪点。 |
| **“字看着很怪/字体不好看/字号对不上/排版很乱”** | **`typeset`** | 1. 建立严格模块化字阶；2. 规范标题（1.1-1.25）与正文行高；3. 段落锁定 45-75ch 最佳阅读宽度。 |
| **“间距太挤/太松散/呼吸感不好/节奏有点别扭”** | **`layout`** | 1. 严格对齐 4px / 8px 网格基线；2. 拉开宏观（Section）与微观（组件内）间距，消除机械等距。 |
| **“加点动效/太死板了/灵动一点/交互生硬”** | **`animate` + `delight`** | 1. 注入基于 Ease-out 的微交互与列表渐次入场（Staggered）；2. 绝对拦截廉价 Bounce 动效。 |
| **“把异常处理做好/考虑下加载态/网络慢怎么办/文字超长/空状态”** | **`harden`** | 1. 补齐全状态：Skeleton 骨架屏、防连击 Loading、Empty 空列表、长文本截断 Tooltip、错误 Toast 边界。 |
| **“帮我检查一下/审查代码/看看合不合规/有没有视觉Bug”** | **`audit` + `critique`** | 1. 运行 59 条确定性反模式规则扫描；2. 检查 WCAG 对比度、键盘 Focus 焦点环与无障碍读屏语义。 |
| **“准备上线/最后把把关/打磨一下细节”** | **`polish`** | 1. 审查 1px 亚像素描边；2. 对齐 Design Tokens；3. 检查 Dark Mode 暗色模式对比与自适应。 |
| **“先理一下原型/这个交互怎么做/先梳理逻辑”** | **`shape`** | 1. 输出信息架构（IA）与核心用户路径；2. 确定状态机（Idle -> Loading -> Success / Error）。 |

## 三、 默认生效的“反 AI 劣质模板（Anti-Slop）”五大铁律

1. **绝对禁止卡片套卡片（No Nested Cards）**：改用呼吸留白与微背景灰阶分割。
2. **绝对禁止死板无倾向纯灰（No Pure Grays）**：中性色必须加入 1%~3% 品牌色微调（Warm Gray / Cool Slate）。
3. **绝对禁止彩色背景用灰字（No Gray on Color）**：有色底严格使用白半透明（`text-white/80`）。
4. **拒绝千篇一律的居中三卡片模板**：根据实际业务场景定制多栏异构或高密度排版。
5. **暗色模式（Dark Mode）深度立体感**：拒绝直接用 `#000000` 纯黑底，使用深灰叠加上边缘内发光（Inner Glow）。
