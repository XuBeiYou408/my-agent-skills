# 企业私域知识库检索技能

## 定位

本技能对接企业本地向量知识库（BGE 离线嵌入 + FAISS + BM25 混合检索 + 重排精排），
专门负责从公司内部私域文档中精准检索并引用事实，严禁凭通识知识猜测内部制度。

## 可检索的典型文档类别

以下类别文档已通过 add_document_to_knowledge 工具持续扩充入库：

| 类别 | 典型问题示例 |
|------|-------------|
| HR 人事制度 | 年假天数怎么算、育儿假有几天、旷工处理规定 |
| 财务报销规范 | 差旅餐补标准、打车费如何报销、报销最晚截止时间 |
| 业务流程 | 合同审批流程、采购需要经过哪些部门、项目立项步骤 |
| 产品与技术文档 | 系统部署步骤、API 接口规范、数据字典 |
| 战略与培训资料 | 公司核心价值观、新员工入职手册、季度 OKR 模板 |

## 核心执行流程

1. 识别检索意图：判断问题是否需要查阅企业私域文档（非公开通识）。
2. 关键词提炼：从用户自然语言中提炼 1~3 个核心检索词或短语。
3. 调用检索工具：调用 search_knowledge_base，传入提炼后的查询词与合适的 top_k。
4. 严格基于召回作答：
   - 仅在召回段落支撑下作答，逐条标注来源文件名。
   - 如果召回内容不足或置信度低，明确告知"未检索到相关规定"，绝不补充猜测。
5. 主动建议扩充：如知识库命中为空，提示用户可通过 add_document_to_knowledge 添加相关文档。

## 多轮对话策略

- 用户追问细节 → 以新的关键词再次调用 search_knowledge_base，不要依赖上一轮结果猜测。
- 用户询问知识库有哪些内容 → 调用 list_knowledge_documents，直接列出清单。
- 用户要新增文档 → 调用 add_document_to_knowledge，传入本地文件绝对路径。

## 严格禁止行为

- 未调用检索工具便直接回答涉及内部制度的问题（哪怕感觉知道）。
- 在召回内容与问题明显不符时强行引用（应告知未检索到）。
- 将检索结果与外部通识混合叙述而不加区分。
